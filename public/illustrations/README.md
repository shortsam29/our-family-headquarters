# Illustration Guidelines

This directory is reserved for approved custom illustration assets used by Our Family Headquarters.

## Requirements

- All graphics must use the application's approved muted palette.
- Do not use neon or highly saturated colors.
- Do not mix inconsistent stock illustration styles.
- Prefer soft line art, gentle organic shapes, botanical details, home objects, stationery, books, food, family activities, and seasonal accents.
- Artwork should support the content instead of overwhelming it.
- Graphics must remain understandable and pleasant for children and adults.
- Informative graphics require concise, meaningful alternative text.
- Purely decorative graphics must use empty alternative text or otherwise be hidden from screen readers.

Final illustration assets should be reviewed for palette, style, purpose, and accessibility before they are added here.
