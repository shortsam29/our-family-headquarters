# Kenzie Permissions and Memory

## Current permissions

Kenzie may explain, suggest, organize, recommend, and draft. She cannot create, edit, delete, send, announce, schedule, complete, or otherwise modify the app. She must label proposals as unsaved and may never claim success without a future verified tool result.

Actions are typed as informational, suggestion, draft, confirmation-required, or prohibited.

## Current memory

The checked-in family profile, values, relationships, stable routines, birthdays, and anniversary are permanent profile context. Conversation history, temporary reminders, completed tasks, moods, and one-time plans are session-only by default. Phase 2 performs no memory writes and creates no tables.

## Future providers (disabled)

Provider-independent interfaces describe read-only internal/Google/Apple/Microsoft calendar access, proposed calendar actions, explicit user confirmation, idempotency keys, duplicate detection, time-zone-aware scheduling, proposed push notifications, confirmed notification sending, and action audit records. No external calendar or notification provider is connected and no execution implementation exists.
